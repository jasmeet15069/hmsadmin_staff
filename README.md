# HMS Staff Website

Standalone staff/admin frontend.

- Dev URL: `http://localhost:8081`
- Login URL: `http://localhost:8081/staff-login`
- Shared backend API: `http://localhost:8787/api`

Run manually:

```powershell
cd "C:\Users\ACXIOM\Desktop\Acxiom Files\hms\staff"
npm install
npm run dev
```

The client/guest frontend is separate under `../client` and runs on port `8080`.
